Cómo leer una consulta

Del HS6 a la identificación comercial mexicana.

La subpartida de seis dígitos es el nivel internacional HS6. México la extiende con una fracción de ocho dígitos y, cuando corresponde, un NICO de dos dígitos. La relación y vigencia se recuperan desde una release identificada; no se infieren solo por la longitud del código.

  1. 85Capítulo · HS2
  2. 8517Partida · HS4
  3. 851713Subpartida · HS6
  4. 85171301Fracción MX · 8 dígitos
  5. 8517130100Fracción + NICO · 10 dígitos
Esta jerarquía explica cómo leer una referencia de datos. No determina qué código corresponde a un producto concreto. Para consultar fuentes oficiales interactivas, revisa el Buscador de fracciones de VUCEM.
