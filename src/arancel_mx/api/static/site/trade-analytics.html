Resumen nacional

Exportaciones, importaciones y saldo mensual. Provienen de la API de Indicadores, no del detalle por mercancía.

Socios comerciales

Ranking y participación por país de origen o destino, a partir de un corte oficial BCMM procesado.

Mercancías

Partida, fracción o NICO cuando el conjunto oficial lo incluya. La jerarquía se conecta con el explorador arancelario.

Reglas de lectura

  • Las cantidades sólo se agregan dentro de la misma unidad de medida.
  • Un saldo compara periodos, moneda, universo y corte equivalentes.
  • Los estados de confidencialidad permanecen visibles: no se infieren ni se imputan.
