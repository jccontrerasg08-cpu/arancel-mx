# FastAPI Public API v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the verified `arancel-mx` consumer surface as a public, GET-only FastAPI v1 service on FastAPI Cloud, pinned to one immutable verified dataset and backed only by read-only DuckDB queries.

**Architecture:** Add a thin `arancel_mx.api` transport adapter over the existing `Dataset` facade. FastAPI lifespan loads and verifies exactly one explicit `data-YYYY.MM.DD` release at process startup, stores the `Dataset` in application state, and routes serialize existing consumer results without reimplementing tariff logic. Source capture, reconciliation, publication, live VUCEM compare, WCO downloads, and all mutations remain outside the HTTP service.

**Tech Stack:** Python >=3.11, FastAPI with `fastapi[standard]`, Pydantic v2 models through FastAPI, DuckDB through the existing `Dataset` facade, pytest + `fastapi.testclient.TestClient`, Ruff including `S` rules, mypy, setuptools, GitHub Actions, FastAPI Cloud.

## Global Constraints

- API access is fully public, read-only, and requires no API key.
- Production requires `ARANCEL_MX_API_DATASET=data-2026.08.15`; the API has no silent `latest` fallback.
- API version is `/v1`; package version, API version, and dataset version remain independent.
- Application routes are GET-only. `OPTIONS` may be generated by CORS middleware. No POST/PUT/PATCH/DELETE application route may exist.
- DuckDB access must remain read-only through `Dataset.connect()` and existing consumer methods.
- No source scraping, legal reconciliation, release creation/publication, dataset mutation, live VUCEM `compare`, WCO download, classifier/LLM, bulk export, job queue, or user-account functionality belongs in v1.
- Search query length is 1..300 characters and result limit is 1..50.
- Suggest query length is 1..300 characters and result limit is 1..20.
- Codes stay strings. Leading zeros and `nico2="00"` must be preserved.
- Official `igi_text` / `ige_text` values such as `Ex.` and `Prohibida` are serialized without reinterpretation.
- CORS is public: origins `*`, credentials disabled, cross-origin methods limited to GET/OPTIONS, and `X-Request-ID` exposed.
- Handled errors use one JSON envelope and must not leak tracebacks, filesystem paths, SQL, or raw internal exception text.
- `search` and `suggest` remain retrieval aids and must not claim tariff classification.
- OpenAPI `/docs`, `/redoc`, and `/openapi.json` remain public and state the informational/non-legal-advice boundary.
- `fastapi[standard]` is added to runtime dependencies because current FastAPI Cloud existing-project documentation requires it for a `pyproject.toml` deployment and documents no GitHub-build mechanism for selecting a package extra.
- `[tool.fastapi] entrypoint = "arancel_mx.api.app:app"` is required for the `src/` layout.
- Existing coverage floor remains 87%.
- Before every material implementation batch, re-check open PRs and current `main`; never write directly to `main`.
- Implementation is TDD: each behavioral slice starts RED, receives the smallest production change, then returns GREEN before the next slice.
